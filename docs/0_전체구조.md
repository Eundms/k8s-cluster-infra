# 전체구조
```
📁 개발자 소스코드
   │
   ▼
🔧 Jenkins (`jenkins-ci-pipeline`)
   - 애플리케이션 빌드
   - Docker 이미지 생성
   - Docker Hub에 push (.env 제외)
   │
   ▼
🐳 Docker Hub
   - 빌드된 이미지 저장
   │
   ▼
📦 Helm Chart Git Repository (`k8s-gitops`)
   - values.yaml: 이미지 태그 등 정의
   - Secret은 Vault에서 주입받도록 구성
   │
   ▼
🚀 ArgoCD 
   - Helm Chart 기준으로 Kubernetes 리소스 동기화
   - Secret은 Vault Agent/CSI 등을 통해 동적으로 주입
   │
   ▼
☸️ Kubernetes 클러스터 (`k8s-cluster-infra`)
   ├── Vault Agent Injector / CSI Driver 설치됨
   ├── Pod 실행 시 Vault에서 시크릿 자동 주입 (env or volume)
   ├── Master/Worker Nodes
   │     └── Docker 이미지 pull → Vault 통해 비밀값 mount
   └── Vault 서버
         └── TLS + Auth 설정 (Kubernetes 인증 등)


📌 Bastion Host : 클러스터 내부에 접근할 유일한 진입점
📌 NAT Gateway : Master/Worker가 간접적으로 인터넷 통신하기 위한 통로

```
# 여러 프로젝트 위치
> Kubernetes에 namespace 다르게 위치 + 환경 다르게 (dev, staging, prod)
- ArgoCD 
- 백엔드 애플리케이션 (dev, staging, prod) 
- 백엔드 모니터링 

| 컴포넌트          | 위치                       | 설명                          |
| ------------- | ------------------------ | --------------------------- |
| `argocd`      | `argocd-system`          | GitOps 도구                   |
| `backend-app` | `dev`, `staging`, `prod` | 환경별 백엔드 앱                   |
| `monitoring`  | `monitoring-system`        Grafana, Prometheus, Loki 등 |


> 로컬에 위치
- Jenkins : `jenkins-ci-pipeline(jekins step 및 설정 과정 명시)`
