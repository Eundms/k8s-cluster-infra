# 보안 그룹 설정 과정

- Bastion Host는 Public Subnet에 위치하며, 외부에서 SSH 접근 허용 (지정된 IP만).
    - Master / Worker 노드는 Private Subnet에 위치하며, 직접 접근 불가.
    - 외부 연결이 필요한 docker image pull, helm repository 접근 등을 위해 NAT Gateway 사용.

- 보안 그룹을 통해 아래와 같은 포트만 허용:
    - Bastion → Master/Worker : 22(SSH), 6443(API), 10250(Kubelet)
    - 노드 간 통신 : etcd, scheduler, controller-manager, calico, kube-proxy 등
    - 외부 → NodePort (30000~32767)
